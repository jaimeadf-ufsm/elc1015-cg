# Viajem sobre asteroides

Um jogo em OpenGL para simular uma viajem sobre um campo de asteroides no espaço.

## Requisitos implementados

### Requisitos básicos

* [x] Camêra com animação suave, utilizando delta time entre frames.
* [x] Asteroides modelados como formas simples (esferas)
* [x] Modo de visualização wireframe e com preenchimento.
* [x] Controle de FPS.


### Requisitos extras
* [x] Nível de detalhe em função da distância (1 pt).
* [x] Carregamento de texturas BMP (1 pt).
* [x] Carregamento de modelos 3D usando o tipo OBJ (até 2pt).
* [x] Modelagem de asteroides elaborados (até 4pt).

## Controles

* Use as teclas `w`, `a`, `s` e `d`, junto ao movimento do mouse, para controlar a câmera.
* Use a tecla `x` para alternar entre o modo wireframe e o modo de preenchimento de polígonos.
